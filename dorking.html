La password non lascia mai il browser per intero: viene trasformata qui in un’impronta SHA-1 e solo i primi 5 caratteri di quell’impronta vengono inviati al servizio Have I Been Pwned (modello “k-anonymity”). Il confronto finale avviene localmente.

Verifica se un’email o un username compaiono in leak di database noti. Sono link verso servizi terzi specializzati: alcuni sono gratuiti, altri richiedono un account o un abbonamento per vedere il dettaglio.

Carica un’immagine o un PDF per estrarne i metadati nascosti (dispositivo, software, date, coordinate GPS nelle foto, autore nei documenti). Il file viene analizzato interamente nel browser: non viene mai caricato su nessun server.

Uso responsabile. Questo strumento si limita ad aggregare link verso servizi pubblici già esistenti (Google, WHOIS, crt.sh, Shodan, LinkedIn, ecc.), a interrogare in modo anonimizzato il database di Have I Been Pwned e ad analizzare localmente, nel tuo browser, i file che carichi tu stesso — nessun file o password lascia mai questa pagina verso server di terzi. Usalo solo su dati che hai il diritto di verificare — la tua azienda, un dominio di tua proprietà, le tue password, i tuoi stessi file, informazioni pubbliche per giornalismo o ricerca sulla sicurezza — nel rispetto della privacy altrui e delle leggi vigenti (GDPR incluso). Non è pensato per sorvegliare, profilare o molestare persone.
